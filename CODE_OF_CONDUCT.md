# Community conduct

Help make Irrigator a welcoming place to learn and contribute.

- Be respectful and constructive. Critique ideas and behavior, not personal traits.
- Welcome questions and acknowledge different backgrounds and experience levels.
- Do not harass, threaten, discriminate, or publish another person's private information.
- Keep issues and pull requests relevant to the project. Describe disagreements
  with concrete examples and proposed improvements.

Maintainers may edit or remove harmful content, close disruptive discussions, or
restrict participation. They should explain moderation decisions when doing so
will not expose private information or put someone at risk.

To report a conduct concern, ask a repository maintainer for a private contact
channel without posting sensitive details publicly. Report security vulnerabilities
through the process in [SECURITY.md](SECURITY.md).
